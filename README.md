# Поиск максимального элемента в слайсе: один поток против горутин

Учебный проект (финальное задание 9 спринта). Программа генерирует большой слайс целых положительных чисел и находит в нём максимум двумя способами: обычным последовательным проходом и параллельно, разбив слайс на `CHUNKS` частей и обрабатывая каждую в отдельной горутине. Затем выводится результат и время работы каждого варианта в микросекундах.

## Что внутри

Весь код находится в пакете `main`.

| Функция | Назначение |
| --- | --- |
| `generateRandomElements(size int) []int` | Генерирует слайс из `size` случайных положительных чисел (`math/rand`). При `size <= 0` возвращает пустой слайс. |
| `maximum(data []int) int` | Находит максимальный элемент последовательным проходом. Для пустого или `nil` слайса возвращает `0`. |
| `maxChunks(data []int) int` | Делит слайс на `CHUNKS` (8) частей, ищет максимум в каждой части в отдельной горутине, ждёт завершения через `sync.WaitGroup` и возвращает максимум из найденных. |

Константы заданы сверху файла:

```go
const (
	SIZE   = 100_000_000 // размер генерируемого слайса
	CHUNKS = 8           // количество частей и горутин
)
```

## Особенности реализации

- **Крайние случаи.** Пустой и `nil` слайс, размер `0` или отрицательный, слайс из одного элемента — все они обрабатываются без паники.
- **Слайс короче `CHUNKS`.** Делить его на 8 частей бессмысленно (появятся пустые куски), поэтому в этом случае `maxChunks` просто вызывает `maximum`.
- **Неравномерное деление.** Если длина слайса не делится на 8 нацело, последний чанк забирает остаток: `end = len(data)`. Так ни один элемент не теряется.
- **Измерение времени.** Используются `time.Now()` и `time.Since(start).Microseconds()`, поэтому время выводится в микросекундах (мкс).

## Запуск

```bash
go run main.go
```

Пример вывода:

```
Генерируем 100000000 целых чисел
Ищем максимальное значение в один поток
Максимальное значение элемента: 1000
Время поиска: 47000 мкс
Ищем максимальное значение в 8 потоков
Максимальное значение элемента: 1000
Время поиска: 9500 мкс
```

## Тесты

```bash
go test ./...
```

В `main_test.go` покрыты: нулевой и отрицательный размер слайса, пустой слайс, слайс из одного элемента, все одинаковые элементы, максимум в начале, в середине и в конце, длина меньше `CHUNKS`, ровно `CHUNKS` и больше. Отдельный тест проверяет, что `maximum` и `maxChunks` дают одинаковый результат на одном и том же наборе данных.
